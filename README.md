## ساخت خودکار APK با GitHub Actions
این پروژه workflow آماده دارد.

1. همه فایل‌های این پروژه را در ریشه Repository قرار بده.
2. به تب **Actions** برو.
3. workflow با نام **Build Android APK** را باز کن.
4. روی **Run workflow** بزن.
5. بعد از سبز شدن اجرای workflow، همان اجرای موفق را باز کن.
6. پایین صفحه در بخش **Artifacts** فایل `DastyarEghsat-debug-apk` را دانلود کن.
7. ZIP دانلودشده را باز کن و فایل `.apk` را روی گوشی Android 12+ نصب کن.

Workflow با هر Push روی هر Branch اجرا می‌شود و همچنین از **Run workflow** قابل اجرای دستی است.
